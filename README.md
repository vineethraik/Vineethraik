### Pulsync

An ESP32 IoT stack: a non-blocking scheduler, Wi-Fi manager, MQTT live link, HTTP enrollment and OTA, and remote config. The self-hosted server uses SQLite and an embedded MQTT broker with a local dashboard. A hosted platform covers the landing site, firmware discovery, and production deploy. The Arduino library is listed in the Arduino Library Registry.

- [pulsync-arduino](https://github.com/Pulsync/pulsync-arduino)
- [pulsync-server](https://github.com/Pulsync/pulsync-server)

### CryoLogger

Cold-chain temperature logger for hospital use. ESP-IDF firmware reads a PT100 through a MAX31865, shows status on an OLED, and keeps an offline queue on external flash. Devices provision Wi-Fi through a captive portal, deliver readings and heartbeats over HTTPS, and take calibration and sample interval from the server. Firmware uses OTA slots. A companion Express dashboard covers devices, graphs, Google sign-in, and SQLite or Postgres storage.

Recent Pulsync and CryoLogger firmware, servers, and docs were written with coding agents (Cursor and similar) in the loop.
